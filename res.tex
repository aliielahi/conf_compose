\paragraph{Statistical Significance.}

We assess whether a protocol consistently improves over each baseline using exact one-sided paired sign tests. Each model-pair and dataset setting provides one paired observation. The sign test is a nonparametric test designed for paired comparisons in which improvement magnitudes are not directly comparable across settings \citep{dixon1946sign}. It uses only the direction of the difference, which is appropriate here because a gain on one benchmark need not have the same numerical meaning as an equally sized gain on another benchmark.

Within each of the 30 settings, we evaluate the protocol and baseline on the same held-out test examples and compute the difference in their metrics. A setting favors the protocol when this difference is positive. The sign test then asks whether positive differences occur more often than expected by chance across the 30 settings. We run the analysis separately for sequence probability and self-reported confidence. For each metric, we test CGF and A-CGF against ZS, MAD, and MAD-D under both confidence estimators, giving 12 comparisons. We control the family-wise error rate across these comparisons using Holm's procedure \citep{holm1979}.

\paragraph{Friedman's Rank Test.}
In addition to Holm's sign test explained in experimental setup, to summarize the relative performance setup of all systems simultaneously, we use Friedman's test followed by Nemenyi critical-difference comparisons \citep{friedman1937ranks,nemenyi1963distribution,demsar2006statistical}. For each model-pair and dataset setting, we rank the six headline systems according to the metric of interest, with rank 1 assigned to the best system. Friedman’s test then assesses whether the average ranks differ more than expected by chance across the matched settings. When this test is significant, the Nemenyi critical difference indicates how far apart two average ranks must be before they can be distinguished at the chosen significance level. this test is reported in Table~\ref{tab:main_rankings}.
